title: "Template Overrides & Customization"
description: "Customize built-in code generator templates locally without forking the Loy CLI binary."
---

Every engineering team has unique conventions: proprietary copyright headers, mandatory observability spans, custom serialization tags, or domain validation interfaces.

Rather than forcing teams to fork the `loy` repository or manually patch generated files, Loy provides a **Template Override Engine** ([ADR-013](/loy/adrs/)):

```text
Template Resolution Order:
  1. Check <targetDir>/.loy/templates/<name>  ──> [If exists, render custom template]
  2. Fallback to embedded CLI templates       ──> [Render default built-in template]
```

## 1. Inspecting & Ejecting Templates

### 1.1 List Available Templates
View all built-in templates available for ejection and customization:

```bash
loy make template list
```

Output:
```text
Available generator templates:
  - agent_rules_agents_md.tmpl
  - agent_rules_claude.tmpl
  - agent_rules_cursor.tmpl
  - command.go.tmpl
  - query.go.tmpl
  - migration.sql.tmpl
  - migration_index_concurrent.sql.tmpl
  - migration_shadow_column.sql.tmpl
  - model.go.tmpl
  - repository.go.tmpl
  - service.go.tmpl
  - handler.go.tmpl
  - request.go.tmpl
  - resource.go.tmpl
  - test.go.tmpl
```

### 1.2 Eject a Template
Dump any embedded template into `.loy/templates/` inside your project root:

```bash
loy make template eject model.go.tmpl
```

Output:
```text
Ejected template model.go.tmpl to .loy/templates/model.go.tmpl
```

## 2. Template Data Model Reference

All Go source generation templates in Loy are rendered using standard `text/template`. The following typed context fields are available inside template scopes:

### 2.1 Entity Identifiers

| Template Variable | Example (`user_account`) | Description |
|---|---|---|
| `{{.Pascal}}` | `UserAccount` | PascalCase name for Go struct and type definitions |
| `{{.Camel}}` | `userAccount` | camelCase name for local variables and parameters |
| `{{.Snake}}` | `user_account` | snake_case name for file names and database tables |
| `{{.Plural}}` | `UserAccounts` | Pluralized PascalCase name for collections |
| `{{.PluralLower}}` | `useraccounts` | Pluralized lowercase name for HTTP URL routes |
| `{{.FeaturePkg}}` | `useraccount` | Flat lowercase package name (safe for case-insensitive filesystems) |
| `{{.ModulePath}}` | `github.com/org/app` | Authoritative module path from `go.mod` |

### 2.2 Flags & Capabilities

| Template Variable | Type | Description |
|---|---|---|
| `{{.DualID}}` | `bool` | `true` when dual-identifier schema (`--dual-id`) is active |
| `{{.MultiTenancy}}` | `bool` | `true` when multi-tenancy is enabled |
| `{{.TenantStrategy}}`| `string` | `rls` for Row Level Security or `column` for explicit column filtering |

### 2.3 Field Definition Model (`{{.Fields}}`)

Looping over `{{range .Fields}}` exposes the following properties on each field:

| Field Property | Example | Description |
|---|---|---|
| `{{.PascalName}}` | `EmailAddress` | PascalCase field identifier for Go struct definitions |
| `{{.SnakeName}}` | `email_address` | snake_case field identifier for database columns |
| `{{.Type}}` | `string`, `int64`, `time.Time` | Go concrete type |
| `{{.IsPointer}}` | `bool` | `true` if field is optional/nullable |
| `{{.IsRequired}}` | `bool` | `true` if validation requires a non-zero value |
| `{{.IsUnique}}` | `bool` | `true` if field carries a unique database constraint |
| `{{.JSONTag}}` | `json:"email_address,omitempty"` | Pre-formatted JSON struct tag |
| `{{.DBTag}}` | `db:"email_address"` | Pre-formatted database struct tag |

## 3. Practical Customization Example

Suppose your company requires all domain models to implement an audit interface and include corporate copyright headers.

Edit `.loy/templates/model.go.tmpl`:

```go title=".loy/templates/model.go.tmpl"
// Copyright (c) 2026 Acme Corp. All rights reserved.
// Code generated by Loy with company conventions.

package domain

import (
	"time"
{{if .DualID}}	"github.com/google/uuid"{{end}}
)

// {{.Pascal}} represents the business domain entity for {{.Name}}.
type {{.Pascal}} struct {
{{if .DualID}}	ID        int64     `json:"id" db:"id"`
	PublicID  uuid.UUID `json:"public_id" db:"public_id"`
{{else}}	ID        int64     `json:"id" db:"id"`
{{end}}
{{range .Fields}}	{{.PascalName}} {{if .IsPointer}}*{{end}}{{.Type}} `{{.JSONTag}} {{.DBTag}}`
{{end}}
	CreatedAt time.Time `json:"created_at" db:"created_at"`
	UpdatedAt time.Time `json:"updated_at" db:"updated_at"`
}

// TableName returns the physical SQL table name for {{.Pascal}}.
func ({{.Pascal}}) TableName() string {
	return "{{.PluralLower}}"
}

// AuditIdentifier satisfies Acme's enterprise security auditing contract.
func (e {{.Pascal}}) AuditIdentifier() string {
{{if .DualID}}	return e.PublicID.String()
{{else}}	return fmt.Sprintf("%d", e.ID)
{{end}}}
```

From now on, whenever an engineer or AI agent runs:

```bash
loy make model invoice amount:float status:string
```

Loy detects the custom override in `.loy/templates/model.go.tmpl` and immediately outputs code containing the Acme copyright header and `AuditIdentifier()` method!
