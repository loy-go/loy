description: "Generate zero-dependency TypeScript interfaces and typed fetch clients directly from Go transport DTOs and routes."
---

Maintaining type safety across fullstack Go and TypeScript applications is traditionally painful:
- Writing OpenAPI YAML by hand drifts out of sync with code.
- Heavy OpenAPI generator CLI tools require Java runtime dependencies, generate thousands of lines of bloated code, and produce convoluted SDK wrappers.
- Manual TypeScript interface authoring introduces silent runtime type mismatches.

Loy eliminates this friction with **Fullstack Typegen**:
```bash
loy gen client [root-dir] --out=frontend/src/api
```

It statically analyzes Go AST structs (`*_request.go`, `*_resource.go`) and registered routes to produce two clean, zero-dependency TypeScript files:
1. **`types.ts`**: Clean TypeScript interfaces for every request and response DTO.
2. **`client.ts`**: A typed API client class (`LoyClient`) wrapping the native Web Fetch API.

---

## 1. Type Mapping Matrix

Loy's AST parser maps Go types to TypeScript according to the following authoritative matrix:

| Go Type Expression | TypeScript Output Type | Nullability & Optionality |
|---|---|---|
| `string` | `string` | Non-nullable |
| `int`, `int32`, `int64`, `uint`, `uint64` | `number` | Non-nullable |
| `float32`, `float64` | `number` | Non-nullable |
| `bool` | `boolean` | Non-nullable |
| `uuid.UUID` | `string` | Formatted UUID string |
| `time.Time` | `string` | ISO 8601 UTC timestamp string |
| `json.RawMessage` | `any` | Arbitrary JSON payload |
| `*T` (Pointer to T) | `T \| null` | Marked as optional (`field?: T \| null`) |
| `[]T` (Slice of T) | `T[]` | Array of T |
| `map[string]V` | `Record<string, V>` | Key-value record |
| `struct` tag `json:"name,omitempty"` | `name?: <Type>` | Marked as optional property |
| `struct` tag `json:"-"` | *Omitted* | Excluded from generated client interface |

## 2. End-to-End Walkthrough

### 2.1 Backend Go Source Definitions

Consider a standard Loy feature slice with request and resource DTOs:

```go title="internal/book/transport/http/request/book_request.go"
package request

type CreateBookRequest struct {
	Title       string   `json:"title"`
	Author      string   `json:"author"`
	Price       float64  `json:"price"`
	DiscountPct *int     `json:"discount_pct,omitempty"`
	Tags        []string `json:"tags"`
	InternalRef string   `json:"-"` // Omitted from API
}
```

```go title="internal/book/transport/http/resource/book_resource.go"
package resource

import (
	"time"
	"github.com/google/uuid"
)

type BookResource struct {
	ID        int64     `json:"id"`
	PublicID  uuid.UUID `json:"public_id"`
	Title     string    `json:"title"`
	Author    string    `json:"author"`
	Price     float64   `json:"price"`
	CreatedAt time.Time `json:"created_at"`
}
```

### 2.2 Generating the Client

Execute:

```bash
loy gen client . --out=frontend/src/api
```

### 2.4 Generated `client.ts`

```typescript title="frontend/src/api/client.ts"
// Code generated by Loy. DO NOT EDIT.

import type { BookResource, CreateBookRequest } from './types';

export interface ClientConfig {
  baseURL?: string;
  fetch?: typeof fetch;
  headers?: Record<string, string>;
}

export class LoyClient {
  private baseURL: string;
  private fetch: typeof fetch;
  private headers: Record<string, string>;

  constructor(config: ClientConfig = {}) {
    this.baseURL = (config.baseURL || '').replace(/\/$/, '');
    this.fetch = config.fetch || globalThis.fetch.bind(globalThis);
    this.headers = config.headers || {};
  }

  private async request<T>(method: string, path: string, body?: any, query?: Record<string, any>): Promise<T> {
    // Zero-dependency native fetch implementation with query parsing & error handling
    ...
  }

  async listBooks(params?: { limit?: number; offset?: number; [key: string]: any }): Promise<BookResource[]> {
    return this.request<BookResource[]>('GET', `/api/v1/books`, undefined, params);
  }

  async getBook(id: string | number): Promise<BookResource> {
    return this.request<BookResource>('GET', `/api/v1/books/${id}`, undefined, undefined);
  }

  async createBook(data: CreateBookRequest): Promise<BookResource> {
    return this.request<BookResource>('POST', `/api/v1/books`, data, undefined);
  }

  async deleteBook(id: string | number): Promise<void> {
    return this.request<void>('DELETE', `/api/v1/books/${id}`, undefined, undefined);
  }
}

export function createClient(config?: ClientConfig): LoyClient {
  return new LoyClient(config);
}
```

## 3. Frontend Integration Examples

### React / Next.js Hook

```tsx title="components/BookList.tsx"
import React, { useEffect, useState } from 'react';
import { createClient } from '../api/client';
import type { BookResource } from '../api/types';

const api = createClient({ baseURL: process.env.NEXT_PUBLIC_API_URL });

export function BookList() {
  const [books, setBooks] = useState<BookResource[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    api.listBooks({ limit: 10 })
      .then(setBooks)
      .finally(() => setLoading(false));
  }, []);

  if (loading) return <div>Loading catalog...</div>;

  return (
    <ul>
      {books.map(b => (
        <li key={b.public_id}>{b.title} — ${b.price.toFixed(2)}</li>
      ))}
    </ul>
  );
}
```
