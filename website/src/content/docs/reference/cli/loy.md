Loy — Go developer platform with Laravel-like DX

### Synopsis

Loy is an opinionated developer platform and CLI toolchain for Go, providing architecture enforcement, typed code generation, and runtime conventions.

### Options

```
  -C, --directory string   Change execution directory
  -h, --help               help for loy
      --json               Output results in JSON format
      --no-color           Disable colored ANSI output
  -q, --quiet              Suppress non-essential output
  -v, --verbose            Enable verbose/debug output
```
