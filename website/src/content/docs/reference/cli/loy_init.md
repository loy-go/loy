Initialize Loy configuration in an existing Go project

```
loy init [flags]
```

### Options

```
  -f, --force           Overwrite existing loy.yaml
  -h, --help            help for init
  -n, --name string     Project name override
  -p, --preset string   Preset to initialize (api, fullstack, minimal, monorepo, web) (default "api")
```
