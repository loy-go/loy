Generate OpenAPI / Swagger documentation from code annotations

### Synopsis

loy doc parses route handlers and doc annotations to generate OpenAPI specifications.

```
loy doc [path] [flags]
```

### Options

```
  -h, --help            help for doc
  -o, --output string   Output directory for OpenAPI specifications (default "docs")
```
