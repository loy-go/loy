## 60-Second Quickstart

```bash
# 1. Install Loy CLI
go install github.com/loy-go/loy/cmd/loy@latest

# 2. Scaffold a new API service with turnkey presets
loy new myapp --preset api --http fiber --db postgres
cd myapp

# 3. Generate a complete 4-layer vertical CRUD slice
loy make crud user name:string email:string:unique role:string

# 4. Enforce Clean Architecture invariants
loy check

# 5. Start the interactive multi-process live reload dashboard
loy dev --tui
```
